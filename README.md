# Java AWT CRUD Application

A desktop GUI application built using **Java AWT** and **MySQL** that allows users to perform **Create, Read, Update, and Delete (CRUD)** operations on structured data through an interactive interface.

---

## Features

- Create new records and store them in the database
- View and retrieve stored records
- Update existing entries
- Delete records from the database
- Simple and user-friendly graphical interface
- Real-time interaction with a MySQL database

---

## Tech Stack

**Frontend**
- Java AWT (GUI)

**Backend**
- Java

**Database**
- MySQL

## How It Works

1. The application connects to a **MySQL database** using JDBC.
2. The **Java AWT interface** allows users to interact with the system.
3. User actions such as adding or editing records trigger **SQL queries**.
4. The database updates accordingly and the interface reflects the changes.
